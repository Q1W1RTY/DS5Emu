# Профили игр — DS5Link 0.1.31

## Использование

В «Настройки контроллера» нажмите «Добавить EXE…» и выберите исполняемый файл самой игры, а не Steam или другой лаунчер. Создаётся копия выбранного профиля. Затем настройте тачпад, мёртвые зоны, курки, LED и звук. Изменения сохраняются автоматически в выбранный профиль. Для удаления привязки выберите профиль и нажмите «Удалить»; EXE игры не удаляется.

Профиль определяется по полному пути активного окна, с учётом разных каталогов и без учёта регистра. Проверка выполняется раз в 500 мс. При переключении на другое приложение возвращаются общие настройки; при переходе в DS5Link сохраняется последний активный профиль. Редактирование профиля другой игры не активирует его: строка «Сейчас» показывает реально применённый профиль. Игра должна иметь активное окно, одного фонового процесса недостаточно. При переносе игры добавьте её новый EXE.

Применение не переподключает контроллер и не меняет режим PS5/Xbox. Приоритет собственных эффектов игры сохранён: уже занятые игрой каналы остаются за ней до переподключения эмуляции, как и раньше.

## Данные и ошибки

Каталог хранится в `%LOCALAPPDATA%\DS5Link\game-profiles.json`. Старые `input-profile.json` и `effects.json` используются как исходный общий профиль, если нового каталога ещё нет, и не перезаписываются. Файл заменяется атомарно. Повреждённый каталог не сбрасывается автоматически; редактирование блокируется с сообщением.

При частичной ошибке применения выполняется попытка восстановления обоих каналов настроек; повторная попытка через 3 секунды. Отправка назначений блокируется на время переключения и при несовпадении активного EXE с применённым профилем. Просроченные ответы ввода от предыдущего поколения настроек отбрасываются.
