# Интерфейс Avalonia

С версии 0.1.50 рабочий проект — `src/DS5Link.Avalonia`.
Он сохраняет компоновку, все шесть вкладок, профили, автосохранение, ввод,
захват аудио и управление службой. Внешние окна рисует Avalonia;
для значка и меню трея сохранён Windows Forms NotifyIcon.

- Шрифт Geologica встроен локально в начертаниях 400/500/600/700.
- Векторный BatteryGauge показывает фактический заряд и состояние зарядки.
- Форматы настроек, pipe и native-движок сохранены.
- `scripts/build.ps1`, `test.ps1`, `package.ps1` и `build-setup.ps1` используют новый проект.
- `--ui-qa` проверяет окна, вкладки, шрифты, батарею, локализацию и ввод без изменения контроллера.

Старая WPF-реализация в `src/DS5Link.App` сохранена как исходный эталон.
Подробности сборки — в [BUILD.md](BUILD.md).
