# Адверсариальное ревью установщика 0.1.4

Дата: 2026-11-02. Область: текущие Install.ps1, InstallPaths.ps1, Uninstall.ps1, Setup.cs и упаковка. Проверяется установщик, а не вся программа или драйверы. Исправления в рамках ревью не выполнялись.

## P1 — распакованный код можно подменить перед повышением прав

Setup.cs:34–43 создаёт комплект в пользовательском TEMP. Проверка хешей выполняется один раз до запуска Install.ps1 (117–121). Install.ps1:11–15 затем запускает тот же файл из TEMP с RunAs. Повышенный процесс читает InstallPaths.ps1, dependencies.json и app из этой же доступной пользователю папки; независимой проверки по доверенному источнику после повышения нет.

Условие: локальный процесс с правом записи в TEMP пользователя меняет скрипт, helper или исполняемые файлы после проверки, например пока открыт запрос UAC. После подтверждения пользователем подменённый скрипт получает права администратора, а подменённый движок может быть зарегистрирован как SYSTEM-служба. Это не обход UAC без подтверждения: используется подтверждение настоящей установки. Проблема унаследована от прежнего bootstrap, новый helper также попадает под неё.

Доказательство: статический путь исполнения и manifest asInvoker. Эксплуатация с повышением прав не запускалась. Защита должна переносить извлечение и проверку доверенного встроенного комплекта в повышенный bootstrap и защищённый каталог. Простая повторная проверка редактируемого files.sha256 недостаточна.

## P1 — квадратные скобки ломают откат и удаление

InstallPaths.ps1:12 допускает обычные имена вида DS5Link [test]. Но Install.ps1:164–167 и Uninstall.ps1:37–41 используют Test-Path без LiteralPath. PowerShell интерпретирует скобки как шаблон. В результате существующая резервная папка не находится при откате; удаление может пропустить существующую папку приложения, а затем убрать её регистрацию. Аналогичные вызовы есть в подготовке каталогов.

Безопасное воспроизведение выполнено в artifacts/review-installer-014: Resolve-DS5InstallPath принял D:\Apps\DS5Link [test]; тестовая папка была перемещена в резервную; Test-Path -LiteralPath вернул true, обычный Test-Path для того же пути — false. Отчёт: artifacts/review-installer-014/brackets.json. Рабочая установка не использовалась.

Исправление: все операции с выбранным путём и его производными должны иметь буквальную семантику; отдельно проверить исходные wildcard-операции копирования. Критерий: полный install/update/failure rollback/uninstall для имени со скобками, без оставшихся файлов или регистрации.

## P2 — поздняя ошибка оставляет частичную регистрацию

Install.ps1:137–145 сначала записывает uninstall-ключ, затем создаёт ярлык. Если Save() или последующее обновление автозапуска завершается ошибкой, catch:161–170 возвращает файлы, но не восстанавливает uninstall-ключ, ярлык, автозапуск и прежние параметры службы полностью. На первой установке удаляется SOFTWARE\DS5Link, но uninstall-ключ остаётся с путём к уже перемещённым файлам. Мастер при следующем запуске читает этот ключ и считает приложение установленным, блокируя выбор другой папки; запись удаления указывает на отсутствующий скрипт. При обновлении могут остаться новая версия в реестре и изменённый режим запуска службы при возвращённых старых файлах.

Доказательство: порядок записи и обработчик catch. Отказ на этой стадии не инъецировался. Предыдущий тест повреждённого vdsd.exe падает до записи uninstall-ключа и не проверяет этот сценарий.

Исправление: сохранять состояние регистрации, службы и ярлыков до изменений и восстанавливать его при откате; для новой установки удалять только созданные этой транзакцией записи. Критерий: искусственный отказ после записи uninstall-ключа и после сохранения ярлыка возвращает исходные файлы и регистрацию, повторная установка доступна.

## Итог и порядок работ

До передачи 0.1.4 другим пользователям исправить передачу доверенного комплекта повышенному процессу, затем буквальную обработку путей и полный откат регистрации. После этого повторить имеющийся изолированный жизненный цикл с дополнительными случаями выше.

Предыдущие успешные проверки подтверждают базовый сценарий с кириллицей/пробелами и отказом запуска службы. Они не подтверждают защищённость передачи через UAC или атомарность всех стадий. Служба пользователя в рамках ревью не останавливалась; продуктовый код, установщик и GitHub не менялись.
