# Выполнение плана исправлений

2026-11-02. Исправления и технический прогон выполнены; расширенная аппаратная и игровая приёмка остаются частичными. Актуальные итоги ниже заменяют промежуточные сведения этого журнала.

## Итог продолжения: кандидат 0.1.5

- Все 11 замечаний получили изменения в коде. Проверки ниже подтверждают конкретные сценарии, а не универсальное отсутствие ошибок.
- Установщик прошёл изолированный повышенный жизненный цикл на D: в папке с кириллицей, пробелами и скобками. Проверены свежая поздняя ошибка с отсутствием остаточной регистрации, поздняя ошибка обновления с восстановлением намеренно испорченного значения, повреждённый движок, обновление и удаление. PID рабочей службы сохранялся.
- Реальный bootstrap проверен на изолированном пакете без драйверов: код выполнялся из защищённой папки Program Files с защищённым ACL; порча внешней копии после встраивания не повлияла на установку. Отчёт: путь в artifacts/install-path-qa-latest.txt.
- 8/8 групп native-тестов, 7 managed-сценариев и 18 UI-сценариев проходят. Добавлены молчащий/медленный TCP-клиент, отмена чтения, резервирование аудиоблока при сбросе потока и recoveryPending. Размеры UI проверены синтетическими областями просмотра; перенос между физическими мониторами с разным DPI отдельно не подтверждён.
- Версия берётся из VERSION: приложение, bootstrap/manifest, package metadata и интерфейс. Диагностический ZIP получает версию сборки; Windows-регистрация — версию установленного EXE.
- Дополнительный риск аудиоочереди устранён передачей владения блоком до транспортной записи. Старое завершение больше не удаляет новый head очереди. Priming и размеры буферов не уменьшались; это не заявление об измеренной задержке.
- Патч движка включает новые заголовки и тесты, проходит reverse-check и применение к чистой копии закреплённого upstream.

## Проверка установленного кандидата

Пользователь разрешил локальное обновление и аппаратный прогон. Установлен 0.1.5, хеши UI/движка сверены с манифестом. Первый запуск сохранил Paused; после явного enable получен Active по Bluetooth.

- Три цикла pause/enable прошли с проверкой отсутствия лишних виртуальных устройств и журнала после освобождения.
- Перезапуск реального UI сохранил паузу.
- Конфликт с безопасным процессом-имитатором имени DSX прошёл; настоящий DSX не запускался.
- Принудительное завершение службы восстановилось примерно за 6.7 секунды с прежним составом виртуальных устройств.
- На установленном сервере молчащий клиент задержал следующий корректный запрос примерно на 1 секунду; медленный неполный запрос не заблокировал следующий. Нормальная остановка службы во время handshake заняла примерно 0.27 секунды, журнал восстановления отсутствовал, повторный запуск и запрос прошли.
- Команды recover и явный выбор единственного подключённого контроллера прошли в Paused. Замена на другой физический контроллер не проверена.
- HID-прогон и четырёхканальная подача звука завершились с exit 0; получены 195360 кадров микрофона при 48000 Гц, голос не сохранялся. Пользователь ответил: «та вроде всё норм, потом нормально в игре потестирую». Это краткое подтверждение цветов, курков, динамика и отдельной хаптики; не строгая оценка задержки.

Подробные локальные результаты: каталог из artifacts/hardware-015-latest.txt. Публичные журналы с идентификаторами устройств не публиковались.

## Что остаётся открытым

Игровую проверку пользователь явно отложил. На новом кандидате не повторены физический USB-переход, разделение каналов наушников, mute с голосом, сон/возврат Windows, другая административная учётная запись и замена A→B на двух физических контроллерах. Поэтому пакет сохраняет candidate=true/hardwareAccepted=false. Закрытый технический дефект и полная аппаратная приёмка — разные статусы.

Рабочая установка обновлена с разрешения пользователя. GitHub не публиковался. Старый принятый native-хеш в обычном релизном профиле сохранён; его нельзя заменять автоматически хешем этого кандидата.
