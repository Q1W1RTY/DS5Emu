# Выполнение плана: локальный кандидат 0.1.29

2026-11-03. Кандидат 0.1.29 собран и установлен локально с разрешения пользователя. Публикации нет. Результаты последующего прогона приведены ниже.

## Выполнено

- R1: output I/O имеет срок 1 с, ожидание очереди 2 с; отмена stop не ожидает mutex отправки; проверяется устаревший input работающей сессии. Добавлен тест реально заблокированного overlapped WriteFile на изолированном named pipe с отменой и дренированием.
- R2: фактический статус capture, повтор старта раз в секунду, сброс статуса по RecordingStopped, проверка смены default endpoint раз в секунду. Старые callbacks фильтруются по capture instance. Использован периодический контроль endpoint вместо подписки на уведомления.
- R3: неудавшаяся настройка возвращается в pending, более новая запись имеет приоритет; закрытие после ошибки требует явного отказа от неприменённых изменений.
- R4: STATUS генерируется при упаковке, обязательного локального файла больше нет.
- R5: новые backup регистрируются в защищённом backups.json с хешем owned-manifest; сохраняется последняя копия. Cleanup использует только зарегистрированные пути и owned-файлы. Legacy backup автоматически не удаляются. Посторонние/изменённые файлы сохраняются.
- R6: бюджет 256 queued replies, 8 МиБ включая отправляемый ответ и горизонт 2 с; тайм-аут отправки 1 с; поколение сессии предотвращает отправку старого ответа новому клиенту. При превышении сессия завершается. Полноценное управление каждым in-flight URB/unlink остаётся отдельной работой.
- Языковые ресурсы ограничены ru, старые известные satellite-файлы удаляются из staging перед publish; UI PDB исключён. Частота effects IPC без активного audio снижена до 10/с. Запрос точности таймера перенесён на lifetime worker.
- ControlPipeServer вынесен из vdsd.cc. Bootstrap patch обновлён с новыми заголовками и тестами.

Сборка прошла. WPF: 0 ошибок/предупреждений; native показывает существующие предупреждения deprecated inet_addr/strncpy. Все 13 CTest-групп, 57 managed, 48 synthetic UI-сценариев, проверки зависимостей и owned-removal проходят. Дополнительно проверены повтор неудавшейся настройки, failed capture, границы USB/IP-бюджета и retention backup с посторонним файлом.

Патч применён к чистому закреплённому upstream, содержимое 126 путей сверено с рабочим деревом. Setup QA и embedded payload verification прошли без установки драйверов/службы.

## Незавершённая часть плана

Проверены Bluetooth HID, короткие эффекты/аудио/микрофон, три цикла pause/enable, повышенный изолированный installer lifecycle и упаковка ZIP без локального STATUS (подробности ниже). Остаются физический USB, наушники/mute, смена default endpoint и сбой реального capture, sleep/resume, другой контроллер и игры. Тест зависшего named-pipe output проверяет общий helper ожидания/отмены, а не весь PS5 lifecycle при зависшем физическом драйвере. Burst импортированного USB/IP-клиента пока не проверен.

Активный A/B CPU/allocations/end-to-end latency, timestamps production audio-очереди, изменение буферов, дальнейшее разделение supervisor/session/audio и замена глобальных состояний ещё не выполнены. Базовые игровые аудиобуферы сохранены. Эти этапы требуют отдельного измеренного прогона; текущий кандидат не считается полностью аппаратно принятым.


## Продолжение: установка и частичная аппаратная приёмка

- Повышенный scripts/qa-install-path.ps1 прошёл 12 стадий: fresh late failure, защищённый bootstrap с подменой внешней копии, upgrade, отклонение неподходящих путей, late rollback, corrupt native rollback и uninstall. PID рабочей службы был сохранён во время fixture.
- После этого установлен собственный проверенный Setup 0.1.29 через elevated embedded bootstrap. Установленные native/UI совпадают с release.json по SHA-256. Версия 0.1.29; Paused сохранился до явного включения из UI.
- Реальный интерфейс проверен через semantic Agent Desktop: запуск, PS5, настройки и закрытие настроек. Полная визуальная/DPI-приёмка этим не заявляется.
- После подтверждения готовности контроллера пользователем включён PS5 по Bluetooth. Input-only probe: 2999 reports за 5 секунд, invalidReports=0.
- HID effect probe и audio-test завершились с кодом 0. Четырёхканальное воспроизведение завершено; microphone получил 195840 frames при 48000 Гц. Семплы не сохранялись. Пользователь подтвердил: цвета, оба курка, динамик и хаптика прошли нормально. Это короткая функциональная оценка, а не измерение игровой задержки.

- 30-секундное наблюдение Active без игрового аудио, с UI и статическими ручными эффектами: 20 интервальных выборок, средняя CPU 0.238% всей мощности CPU, максимум 1.223%; суммарный working set UI+службы 160.64 МиБ, private bytes 88.81 МиБ. Сборщик создаёт собственную нагрузку; это один текущий сценарий, не A/B и не доказательство ускорения относительно 0.1.28.

UI перепубликован; native использован из уже собранного кандидата, драйверные установщики — из проверенного кеша. Это закрывает проверку конкретной зависимости от STATUS, но не означает сборку native toolchain с нуля на чистой Windows.
